# 문제8 음성에서 문자로

## 1. 문제 개요

이전 문제에서 음성 녹음 기능을 구현하여 사용자의 음성을 파일로 저장할 수 있었다. 하지만 녹음 파일이 많아질수록 원하는 내용을 찾기 위해 음성 파일을 하나씩 직접 들어야 하는 불편함이 있다.

이번 문제의 목표는 `records` 폴더에 저장된 음성 파일 목록을 불러오고, 선택한 음성 파일을 STT 기능으로 텍스트 변환한 뒤, 음성 파일 내 시간 정보와 인식된 텍스트를 CSV 파일로 저장하는 것이다.

## 2. 수행 조건

이번 문제에서 요구한 주요 조건은 다음과 같다.

- 문제 7에서 녹음된 음성 파일 목록 불러오기
- 음성 파일에서 텍스트를 추출하는 STT 기능 구현
- 음성이 텍스트로 잘 인식되는지 확인
- STT 결과를 CSV 파일로 저장
- CSV 파일에는 음성 파일 내 시간과 인식된 텍스트 저장
- CSV 파일 이름은 음성 파일 이름과 동일하게 하고 확장자만 `.csv`로 저장
- 전체 내용을 `javis.py` 파일에 추가
- 파일 처리 부분 예외 처리 적용
- 경고 메시지 없이 실행되도록 구현

## 3. 사용한 라이브러리

이번 문제에서는 다음 라이브러리를 사용하였다.

| 라이브러리 | 구분 | 사용 목적 |
|---|---|---|
| `os` | Python 기본 라이브러리 | 폴더 및 파일 경로 처리 |
| `csv` | Python 기본 라이브러리 | STT 결과를 CSV 파일로 저장 |
| `wave` | Python 기본 라이브러리 | WAV 파일 길이 확인 |
| `queue` | Python 기본 라이브러리 | 녹음 데이터 임시 저장 |
| `datetime` | Python 기본 라이브러리 | 녹음 파일명 생성 |
| `sounddevice` | 외부 라이브러리 | 마이크 입력 녹음 |
| `SpeechRecognition` | 외부 라이브러리 | 음성 파일의 STT 처리 |

문제 조건에서 STT와 음성 녹음 부분은 외부 라이브러리 사용이 가능하므로, 녹음에는 `sounddevice`, STT에는 `SpeechRecognition`을 사용하였다.

## 4. 설치 방법

음성 녹음 및 STT 처리를 위해 다음 라이브러리를 설치한다.

```bash
pip install sounddevice SpeechRecognition
