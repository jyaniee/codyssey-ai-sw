# 문제8 음성에서 문자로

## 1. 문제 개요

이전 문제인 `문제가 자비스가 필요해!`에서 마이크를 이용해 음성을 녹음하고, 녹음 파일을 `records` 폴더에 저장하는 기능을 구현하였다.

이번 문제에서는 이전 문제에서 생성된 녹음 파일을 다시 활용한다. `records` 폴더에 저장된 음성 파일 목록을 불러오고, 선택한 음성 파일에서 STT(Speech to Text)를 이용해 텍스트를 추출한 뒤, 음성 파일 내 시간 정보와 인식된 텍스트를 CSV 파일로 저장하는 것이 목표이다.

과제 파일은 이전 문제의 `javis.py`를 그대로 수정하지 않고, 별도의 폴더인 `c02-p08-voice2text`를 생성한 뒤 `voice2text.py` 파일로 분리하여 작성하였다.

## 2. 수행 조건

이번 문제에서 요구한 주요 조건은 다음과 같다.

* 문제 7에서 녹음된 음성 파일 목록 불러오기
* 음성 파일에서 텍스트를 추출하는 STT 기능 구현
* 음성이 텍스트로 잘 인식되는지 확인
* STT 결과를 CSV 파일로 저장
* CSV 파일에는 음성 파일 내 시간과 인식된 텍스트 저장
* CSV 파일 이름은 음성 파일 이름과 동일하게 하고 확장자만 `.csv`로 저장
* 전체 코드를 `voice2text.py` 파일로 작성
* 파일 처리 부분 예외 처리 적용
* 경고 메시지 없이 실행되도록 구현

## 3. 이전 문제와의 연결

이전 문제에서는 다음 기능을 이미 구현하였다.

* 마이크 입력을 통한 음성 녹음
* `records` 폴더 생성
* 날짜와 시간 기반의 `.wav` 파일 저장
* 녹음 장치 및 파일 저장 관련 예외 처리

위 내용은 이전 문제인 `문제가 자비스가 필요해!` 보고서에서 자세히 다루었으므로, 이번 보고서에서는 중복해서 설명하지 않는다.

이번 문제에서는 이전 문제에서 생성된 `.wav` 녹음 파일을 입력 데이터로 사용하고, 이를 텍스트 데이터로 변환하여 CSV 파일로 저장하는 기능만 새롭게 구현하였다.

## 4. 폴더 구조

이번 문제는 이전 과제 파일과 분리하여 관리하였다.

```text
codyssey-ai-sw/
├─ c02-p07-javis/
│  ├─ javis.py
│  └─ records/
│     ├─ 20260514-073015.wav
│     └─ ...
│
└─ c02-p08-voice2text/
   ├─ voice2text.py
   └─ README.md
```

`voice2text.py`는 이전 문제의 `records` 폴더에 접근하여 `.wav` 파일 목록을 불러온다.

## 5. 사용한 라이브러리

이번 문제에서 사용한 주요 라이브러리는 다음과 같다.

| 라이브러리               | 구분              | 사용 목적              |
| ------------------- | --------------- | ------------------ |
| `os`                | Python 기본 라이브러리 | 폴더 및 파일 경로 처리      |
| `csv`               | Python 기본 라이브러리 | STT 결과를 CSV 파일로 저장 |
| `wave`              | Python 기본 라이브러리 | WAV 파일 길이 확인       |
| `SpeechRecognition` | 외부 라이브러리        | 음성 파일의 STT 처리      |

음성 녹음 기능은 이전 문제에서 구현했으므로, 이번 문제에서는 녹음 관련 라이브러리와 녹음 처리 과정은 자세히 다루지 않는다.

문제 조건에서 STT 기능은 외부 라이브러리 사용이 가능하므로, 음성 인식을 위해 `SpeechRecognition`을 사용하였다.

## 6. 설치 방법

STT 처리를 위해 `SpeechRecognition` 라이브러리가 필요하다.

```bash
pip install SpeechRecognition
```

프로그램은 다음 명령어로 실행한다.

```bash
python voice2text.py
```

## 7. 주요 구현 내용

### 7.1 이전 과제의 records 폴더 접근

이번 과제는 별도 폴더에서 실행되므로, 이전 문제의 녹음 파일이 저장된 `records` 폴더를 상대 경로로 접근하도록 구현하였다.

```python
BASE_DIR = os.path.dirname(os.path.abspath(__file__))

RECORDS_DIR_NAME = os.path.join(
    BASE_DIR,
    '..',
    'c02-p07-javis',
    'records'
)
```

이를 통해 `voice2text.py`가 있는 위치를 기준으로 이전 과제의 `records` 폴더를 찾을 수 있다.

### 7.2 녹음 파일 목록 불러오기

`get_record_files()` 함수는 `records` 폴더에 저장된 파일 중 `.wav` 확장자를 가진 파일만 불러온다.

```python
if file_name.lower().endswith('.wav'):
    wav_files.append(os.path.join(RECORDS_DIR_NAME, file_name))
```

불러온 파일 목록은 이름순으로 정렬하여 출력 순서가 일정하도록 하였다.

```python
wav_files.sort()
```

### 7.3 음성 파일 선택 기능

`print_record_files()` 함수는 녹음 파일 목록을 번호와 함께 출력한다.

```python
for index, file_path in enumerate(record_files, start=1):
    print(f'{index}. {file_path}')
```

이후 사용자가 변환할 파일 번호를 입력하면, 해당 번호에 해당하는 음성 파일을 선택한다.

입력값이 숫자가 아니거나 목록 범위를 벗어나면 오류 메시지를 출력하고 다시 입력받도록 하였다.

### 7.4 음성 파일 길이 확인

음성 파일 내 시간 정보를 기록하기 위해 `wave` 라이브러리로 WAV 파일의 길이를 계산하였다.

```python
with wave.open(audio_file_path, 'rb') as wave_file:
    frame_count = wave_file.getnframes()
    frame_rate = wave_file.getframerate()
```

전체 재생 시간은 프레임 수를 프레임 레이트로 나누어 계산하였다.

```python
duration = frame_count / frame_rate
```

이 값은 음성 파일을 일정 시간 단위로 나누어 STT 처리하는 데 사용된다.

### 7.5 STT 처리

`speech_to_text()` 함수는 선택된 음성 파일을 텍스트로 변환한다.

```python
def speech_to_text(audio_file_path):
```

음성 파일은 한 번에 전체를 처리하지 않고, 일정 시간 단위로 나누어 인식한다.

```python
STT_CHUNK_SECONDS = 10
```

각 구간의 음성 데이터는 `recognizer.record()`를 이용해 읽어온다.

```python
audio_data = recognizer.record(
    source,
    duration=STT_CHUNK_SECONDS
)
```

이후 `recognize_google()`을 사용하여 한국어 음성을 텍스트로 변환한다.

```python
recognized_text = recognizer.recognize_google(
    audio_data,
    language='ko-KR'
)
```

인식에 실패한 구간은 빈 문자열로 저장하여, CSV 파일에서 해당 시간대에 인식 결과가 없었음을 확인할 수 있게 하였다.

### 7.6 CSV 파일 저장

STT 결과는 음성 파일명과 동일한 이름의 `.csv` 파일로 저장한다.

```python
def create_csv_file_name(audio_file_path):
    file_name_without_extension = os.path.splitext(audio_file_path)[0]

    return file_name_without_extension + '.csv'
```

예를 들어 입력 파일이 다음과 같다면:

```text
records/20260514-073015.wav
```

결과 파일은 다음 이름으로 저장된다.

```text
records/20260514-073015.csv
```

CSV 파일에는 다음 두 가지 정보를 저장하였다.

| 컬럼     | 의미                 |
| ------ | ------------------ |
| `time` | 음성 파일 내 시간         |
| `text` | 해당 시간 구간에서 인식된 텍스트 |

## 8. 실행 결과

프로그램을 실행하면 이전 문제에서 생성된 `.wav` 파일 목록이 출력된다.

```text
녹음 파일 목록
------------------------------------------------------------
1. ../c02-p07-javis/records/20260514-073015.wav
2. ../c02-p07-javis/records/20260514-073240.wav
------------------------------------------------------------
```

파일 번호를 입력하면 STT 변환이 시작된다.

```text
텍스트로 변환할 음성 파일 번호를 입력하세요: 1
```

변환 중에는 시간별 인식 결과가 출력된다.

```text
STT 변환 시작: ../c02-p07-javis/records/20260514-073015.wav
음성 파일 길이: 25.40초
------------------------------------------------------------
[00:00] 오늘 화성 기지의 산소량을 확인했다
[00:10] 식량도 얼마 남지 않았다
[00:20] 인식된 텍스트 없음
```

변환이 완료되면 같은 이름의 CSV 파일이 생성된다.

```text
CSV 파일 저장 완료: ../c02-p07-javis/records/20260514-073015.csv
```

## 9. 예외 처리

이번 문제에서는 다음 예외 상황을 고려하였다.

| 예외 상황                      | 처리 방식           |
| -------------------------- | --------------- |
| 이전 문제의 `records` 폴더가 없는 경우 | 오류 메시지 출력       |
| 녹음 파일 목록을 읽을 수 없는 경우       | 오류 메시지 출력       |
| `.wav` 파일이 없는 경우           | 안내 메시지 출력       |
| 파일 번호 입력이 잘못된 경우           | 오류 메시지 출력 후 재입력 |
| WAV 파일 정보를 읽을 수 없는 경우      | 오류 메시지 출력       |
| STT 라이브러리가 설치되지 않은 경우      | 설치 안내 메시지 출력    |
| 음성을 텍스트로 인식하지 못한 경우        | 빈 문자열로 저장       |
| STT 요청 중 오류 발생             | 오류 메시지 출력       |
| CSV 저장 중 오류 발생             | 오류 메시지 출력       |

## 10. 결과 및 느낀 점

이번 문제를 통해 이전 문제에서 생성한 음성 파일을 다시 활용하여 텍스트 데이터로 변환하는 기능을 구현할 수 있었다.

이전 문제에서는 음성을 파일로 저장하는 것에 초점을 두었다면, 이번 문제에서는 저장된 음성 파일을 검색 가능한 텍스트 데이터로 변환하는 흐름을 구현하였다.

음성 파일을 일정 시간 단위로 나누어 처리하면, 어떤 시점에 어떤 내용이 말해졌는지 확인할 수 있다. 또한 CSV 파일로 저장하면 이후 검색, 정리, 분석 작업에 활용하기 쉽다.

다만 STT 결과는 녹음 품질, 발음, 주변 소음, 인터넷 연결 상태 등에 영향을 받을 수 있다. 따라서 실제 서비스에서는 더 긴 음성 파일 처리, 문장 보정, 오프라인 STT 모델 적용 등의 개선도 고려할 수 있다고 느꼈다.
