# 문제가 자비스가 필요해!

## 1. 문제 개요

화성 기지에서 생활을 기록하기 위해 매일 일지를 작성해야 하지만, 직접 키보드로 기록하는 것은 번거롭고 비효율적이다.

이번 문제의 목표는 시스템의 마이크를 인식하여 사용자의 음성을 녹음하고, 녹음된 파일을 날짜와 시간 정보를 포함한 이름으로 저장하는 것이다.

작성한 코드는 `javis.py` 파일로 저장하며, 녹음 파일은 `records` 폴더에 저장되도록 구현하였다.

## 2. 수행 조건

이번 문제에서 요구한 주요 조건은 다음과 같다.

- 시스템의 마이크를 인식하고 음성을 녹음하는 기능 구현
- 음성 녹음 부분은 외부 라이브러리 사용 가능
- 녹음 파일은 Python 앱이 실행되는 하위의 `records` 폴더에 저장
- 녹음 파일 이름은 녹음 날짜와 시간을 기준으로 저장
- 전체 코드는 `javis.py` 파일로 저장
- Python 3.x 버전 사용
- 파일 처리 부분에 예외 처리 적용
- 경고 메시지 없이 실행되도록 구현

## 3. 사용한 라이브러리

이번 문제에서는 다음 라이브러리를 사용하였다.

| 라이브러리 | 구분 | 사용 목적 |
|---|---|---|
| `os` | Python 기본 라이브러리 | 폴더 생성 및 파일 경로 처리 |
| `queue` | Python 기본 라이브러리 | 녹음 데이터를 임시 저장 |
| `wave` | Python 기본 라이브러리 | WAV 파일 생성 및 저장 |
| `datetime` | Python 기본 라이브러리 | 날짜와 시간 기반 파일명 생성 |
| `sounddevice` | 외부 라이브러리 | 마이크 입력을 통한 음성 녹음 |

문제 조건상 음성을 녹음하는 부분은 외부 라이브러리 사용이 가능하므로, 마이크 입력을 받기 위해 `sounddevice`를 사용하였다.

## 4. 설치 방법

음성 녹음을 위해 `sounddevice` 라이브러리가 필요하다.

다음 명령어로 설치할 수 있다.

```bash
pip install sounddevice
```
설치 후 다음 명령어로 프로그램을 실행한다.
```bash
python javis.py
```

## 5. 주요 구현 내용

### 5.1 records 폴더 생성
녹음 파일은 `records` 폴더에 저장되어야 하므로, 프로그램 실행 시 해당 폴더가 없으면 자동으로 생성하도록 구현하였다.
```python
os.makedirs(RECORDS_DIR_NAME, exist_ok=True)
```

### 5.2 녹음 파일명 생성
녹음 파일의 이름은 녹음 날짜와 시간을 기준으로 생성하였다.
```python
now = datetime.now()
file_name = now.strftime('%Y%m%d-%H%M%S') + '.wav'
```
예를 들어 2026년 5월 14일 7시 30분 15초에 녹음을 시작하면 다음과 같은 파일명이 생성된다.
```
20260514-073015.wav
```

### 5.3 마이크 입력 녹음
마이크 입력은 `sounddevice.RawInputStream()`을 사용하여 처리하였다.

```python
with sd.RawInputStream(
    samplerate=SAMPLE_RATE,
    blocksize=1024,
    dtype='int16',
    channels=CHANNELS,
    callback=audio_callback
):
```

녹음 중 입력되는 음성 데이터는 콜백 함수에서 `queue.Queue()`에 저장된다.
```python
audio_queue.put(bytes(indata))
```
사용자가 Enter 키를 누르면 녹음이 종료되고, 큐에 저장된 음성 데이터를 WAV 파일로 저장한다.

### 5.4 WAV 파일 저장
녹음된 음성은 Python 기본 라이브러리인 `wave`를 사용하여 `.wav` 파일로 저장하였다.
```python
with wave.open(record_file_path, 'wb') as wave_file:
    wave_file.setnchannels(CHANNELS)
    wave_file.setsampwidth(SAMPLE_WIDTH)
    wave_file.setframerate(SAMPLE_RATE)
```
이번 구현에서는 다음 설정을 사용하였다.
| 항목      | 값       |
| ------- | ------- |
| 샘플링 레이트 | 44100Hz |
| 채널 수    | 1       |
| 샘플 폭    | 2바이트    |
| 저장 형식   | WAV     |

## 6. 예외 처리
이번 문제에서는 다음과 같은 예외 상황을 고려하였다.

| 예외 상황                     | 처리 방식          |
| ------------------------- | -------------- |
| `sounddevice`가 설치되지 않은 경우 | 설치 안내 메시지 출력   |
| `records` 폴더 생성 실패        | 오류 메시지 출력 후 종료 |
| 파일 저장 중 오류 발생             | 오류 메시지 출력      |
| 마이크 장치 사용 중 오류 발생         | 오류 메시지 출력      |

이를 통해 파일 처리 및 마이크 입력 과정에서 오류가 발생해도 프로그램이 비정상적으로 종료되지 않도록 하였다.

```
저장된 파일: records\20260514-073015.wav
```

녹음 파일은 `records` 폴더 안에 날짜와 시간 기반 이름으로 저장된다.

## 8. 결과 및 느낀점
이번 문제를 통해 Python에서 마이크 입력을 받아 음성을 파일로 저장하는 방법을 확인할 수 있었다.

파일명에 날짜와 시간을 포함하면 여러 번 녹음하더라도 파일명이 중복되지 않고, 녹음 시점을 쉽게 확인할 수 있다는 장점이 있다.

또한 음성 데이터 저장을 위해 외부 라이브러리와 Python 기본 라이브러리를 함께 사용하는 방법을 익힐 수 있었다.
